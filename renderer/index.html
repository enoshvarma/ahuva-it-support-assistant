On-site procedure

      
    

    

      
Before touching a production switch

      
    
        
  1. Confirm scope with the client in writing — which ports, VLANs, switches.
    2. 
        
  2. Backup first: run show running-config, then use Backup running-config above the console.
    3. 
        
  3. Record model / firmware / serial (show version).
    4. 
        
  4. Capture current state: show vlan brief, show interface status.
    5. 
        
  5. Disruptive work (reload, uplinks, STP, mgmt IP) → agree a maintenance window first.
    6. 
      

      
During changes

      
    
        
  1. One small change at a time; verify with a show command after each block.
    2. 
        
  2. Never change the management IP over SSH without console fallback.
    3. 
        
  3. Keep a change log — the console output here is your record.
    4. 
      

      
After changes

      
    
        
  1. Verify end-to-end (ping gateway, MAC table, client DHCP).
    2. 
        
  2. Save config: copy running-config startup-config.
    3. 
        
  3. Fresh backup + update the handover document.
    4. 
        
  4. Client sign-off.
    5. 
      

      
If something breaks

      
Can't fix in 15 minutes → roll back to the backup, restore service first, diagnose after. Inform the project lead.
